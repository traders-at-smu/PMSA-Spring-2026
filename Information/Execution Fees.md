# Kalshi Fee Schedule

### Taker

```jsx
fees = round up(0.07 x C x P x (1-P)) 
P = the price of a contract in dollars (50 cents is 0.5) 
C = the number of contracts being traded 
round up = rounds to the next cent 
```

```jsx
P = the price of a contract in dollars (50 cents is 0.5)

round up = rounds to the next cent 
```
